# Arcadia

A beautiful, native macOS home for all your games — from the Atari 2600 to the PlayStation 5.

Arcadia is a SwiftUI frontend that installs the best open-source emulator for each system,
scans your game folders, fetches box art and launches games with one click.

> Status: early development.
